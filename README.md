# PMR - Harbor manga source repo

A Harbor manga source repo hosting a plugin for [atsu.moe](https://atsu.moe/).

## Install

In Harbor: **Manga > Set up a source > Extensions**, paste this repo URL:

```
https://raw.githubusercontent.com/wesazx/RRO/main/repo.json
```

Then install the **Atsu** plugin.

## What it provides
- Popular / search (48 per page)
- Series detail (title, author, synopsis, status, year, cover)
- Chapter list + page images
- Genre and tag filters
